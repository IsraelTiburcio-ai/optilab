Vercel ESM hotfix — local verification
Date: 2026-11-05
Incident: ERR_MODULE_NOT_FOUND Cannot find module '/var/task/server/academic/vercel'
Impact: production Vercel function only; local tsx/Vite paths were masking the missing ESM extensions.

Root cause:
- package.json has "type": "module".
- Vercel transpiles API TypeScript to .js but preserves relative import specifiers.
- Node ESM does not resolve extensionless paths like ./server/academic/vercel.

Fix:
- Added .js to every relative import in server/academic/**/*.ts and api/v1/[operation].ts (145 imports).
- Catalog JSON remains a static JSON import with `with {type:'json'}`; no runtime readFileSync.
- No Firebase, authorization, academic logic, Rules, IAM, billing or vercel.json behavior changed.

Verification:
