# Capturas del panel local

Capturas sintéticas de la suite Playwright, con identificadores ocultos y sin tokens ni correos. No representan datos reales ni QA físico de la profesora.

Regeneración opcional: `TEACHER_CAPTURE=1` al ejecutar el caso Chromium `responsive 1440` de `test:teacher:ui`, con el entorno emulado descrito en `docs/TEACHER-PANEL.md`. No se capturan pantallas automáticamente en fallos ni se suben trazas con secretos.
